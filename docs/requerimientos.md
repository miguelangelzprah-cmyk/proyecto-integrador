# Requerimientos del proyecto

## Requerimientos funcionales

| ID | Requerimiento |
|----|---------------|
| RF1 | Publicar un sitio web institucional. |
| RF2 | Respaldar los datos cada noche. |
| RF3 | Mostrar el estado de los servicios en un panel de monitoreo. |

## Requerimientos no funcionales

| ID | Requerimiento |
|----|---------------|
| RNF1 | Disponibilidad >= 99 % en horario académico. |
| RNF2 | Solo puertos 22, 80 y 443 abiertos hacia los usuarios. |
| RNF3 | Alerta ante la caída de un servicio en menos de 5 minutos. |
| RNF4 | Poder agregar un servicio nuevo sin modificar los existentes (cada servicio en su propio contenedor). |
